# 官方客户端与同步服务器连接规划

状态：产品方向已确认；普通用户同步与运行时服务器连接闭环尚未开放。

确认日期：2026-10-12（Asia/Shanghai）。

本文面向产品、Manager、Rust sync 与服务端维护者，定义同一官方客户端支持官方端点和用户自部署后端的目标、切换边界与验收。本文不冻结新的 HTTP schema、FFI ABI、密码协议、账号系统或正式部署配置。

## 产品交付目标

同一平台、同一正式发布渠道的同一个官方客户端产品包，必须支持在 Manager 运行时选择“官方同步服务”或“自部署同步服务器”，保存服务器地址后使用兼容后端，无需修改源码、重新编译、重签名或下载实例专用包。输入法与 Manager 的版本 / ABI 关系继续由产品载体约束，不因连接地址不同重新打包。

官方端点纳入正式产品交付规划；域名、服务范围、开放时间和运营条件另行确认。尚未开放时显示不可用原因，仍允许规划中的自部署连接路径，不用示例地址或本地测试服务冒充官方端点。输入与本地个人化始终离线可用，官方账户和官方端点在线不得成为本地输入或兼容自部署同步的必要条件。

当前 Go 后端是单用户自部署模型。官方托管涉及的用户 / 同步域隔离、配额和运维必须单独评审，不将现有 bearer owner 模型直接描述为多用户官方云。发行授权继续以根 LICENSE 和单独授权为准。

## Manager 与核心职责

- Manager 提供服务归属、地址、连接校验、兼容状态、当前同步域与停止 / 切换入口。
- Rust sync runtime 负责网络、设备授权、密钥、合并、cursor 与错误真相；Flutter 不新建同步协议或绕过 FFI 直接操作 userdb。
- 平台输入壳不参与服务器选择或每次按键联网；服务器不可用不影响输入热路径。
- 官方与自部署使用同一兼容协议与相同的服务端不可信边界。P0 永不同步，P1 原始事件仍只在本地，只有允许的 P2 对象以端到端加密形式同步。

## 连接与切换

1. 用户明确选择官方服务或输入自部署地址；非 secret 地址配置与认证凭据分别存储。
2. 发送凭据和同步对象前，以有界、无凭据请求核对服务器身份、协议与能力，展示错误 TLS、认证缺失和不兼容原因。
3. 用户显式加入目标同步域，并通过受支持设备 backend、设备授权或恢复流程建立资格；服务登录成功不等于取得密文解密或设备加入权。
4. 切换前停止旧实例同步并处理未完成操作；旧请求和回调不得在新配置生效后继续提交。
5. 新实例重新校验资格。设备授权、访问凭据、key epoch、远端 cursor、恢复状态和连接摘要按实例与同步域隔离；相同设备 ID、对象 ID 或账号名称不表示属于同一域。

改地址不是迁移，不自动上传现有词库、复制恢复秘密、复用旧域密钥或将旧域对象写入新服务器。保留本地个人化不等于允许把它带到新域；迁移 / 重新同步需要独立用户意图、密钥与删除语义评审。失败不得静默回退官方端点或清空本地库。

## 兼容与安全要求

正式远端使用验证有效的 HTTPS；局域网地址、端口、证书信任与代理策略在实施前明确支持范围，不通过全局忽略证书错误实现自部署。发现响应、重定向和其他 origin 不得获得原实例凭据。

连接状态需区分未配置、官方未开放、未授权、证书错误、不兼容、离线、可同步与受产品 gate 阻断；地址已保存或本地资格 run 成功不能显示为真实用户同步可用。发现协议与兼容窗口在后续同步产品批次冻结，不增加第二套状态真相源。

## 当前事实与后续批次

现有 Manager 保存自部署地址草案并展示净化健康摘要；普通真实远端同步仍保持 `user_sync_enabled=false`，本地 HTTPS 合成资格入口不构成用户成功路径。历史 M3 退出和 macOS / Linux 证据不因本规划改写。

当前平台顺位继续由[当前状态](status/current.md)维护。后续同步开放前分批完成：

1. 冻结实例 / 同步域配置、协议发现与 TLS、凭据安全存储和旧草案迁移。
2. 通过 Rust / FFI 接通运行时服务器选择、授权、停止 / 切换与状态投影。
3. 验证密钥、cursor、tombstone、恢复和设备撤销的域隔离，保持现有隐私 / production gate。
4. 用同一候选产品包取得官方和自部署目标的独立连接、备份恢复与升级证据；官方托管与多用户隔离另行验收。

这些是新增交付要求，不宣称旧 M3 范围已经覆盖；离线 Alpha、首版真实用户同步关闭与当前平台维护顺序不被本次文档更新替代。

## 验收标准

- 同一个未改动的产品包连接官方端点和独立自部署实例；选择地址、授权、同步、停止、重启与切换不依赖构建参数。
- 官方与自部署路径按实际开放范围分别取得真实目标证据；官方尚未上线不额外阻塞通过既有 production gate 的自部署路径，未验收一侧明确标记未开放。完整双端点交付需两侧证据，合成或 loopback 不能解锁普通用户同步。
- 两个实例的 token、设备授权、key epoch、cursor、对象与恢复状态不会串用；延迟响应、并发切换、失败重试不泄露或错写。
- 断网或官方服务故障不影响本地输入、个人化及自部署路径；不能自动改目标、降级加密或复活 tombstone。
- 服务器存储 / 日志不含 P0、P1 原始事件、内容明文或恢复秘密；错误提示与诊断只保留允许的净化摘要。
