### 方向事件根因复盘

- 当前 macOS 26.5 SDK `IMKCandidates.h` 明确：`IMKCandidatesSendServerKeyEventFirst=YES` 时事件先到 controller，若返回未处理则继续送到候选窗；`candidateSelectionChanged:` 用于用户在候选窗移动时通知 controller。本轮实现与该公开契约一致，但 macOS 26.5.2 实机右方向后没有视觉或提交索引变化。
- 现有证据不能区分事件是否抵达候选面板、面板是否改变内部 `selectedCandidate`、或 callback 是否触发。下一方案不能继续依赖同一隐式 fallback，也不能回到已证伪的程序化选择。
- 单一候选方案是由 controller 保持优先接收，四方向显式调用候选面板继承自 `NSResponder` 的公开 `keyDown:`，记录调用前后 `selectedCandidate`、callback index 与最终提交；Space/Enter 继续由 controller 处理。该方案先评审，不在本批次直接生成新 build。

### 公开契约复盘与正式决策

- 交叉核对 Apple InputMethodKit 在线文档、macOS 26.5 SDK `IMKCandidates.h`、`IMKInputController.h`、`IMKInputSession.h`、`TextInputSources.h` 与正式薄壳。公开契约只保证候选窗/controller 的事件优先顺序、用户活动 callback、identifier selection 和输入法专用 command menu；没有保证直接调用继承的 `keyDown:` 等价于系统路由，也没有保证程序化 selection 同步重绘视觉。
- 证据矩阵收敛为三条失败 `IMKCandidates` 路径和一条正式 AppKit 路径：build 28 的 engine/FFI/Space index 正确但视觉失败；隐式 fallback 无选择迁移；显式 `keyDown:` 的 panel/callback/视觉/提交均停在 index 0。candidate-first 虽有事件顺序契约，但仍依赖同一不透明 panel 且没有实机证据，不生成第三个签名 probe。
- SDK `IMKInputSession.h` 明确给自建候选窗提供 client `windowLevel` 和全局行矩形，并说明候选窗使用 client level 加一；结合 AppKit nonactivating panel、collection behavior 和 accessibility 公开接口，正式方向改为 macOS 专用 AppKit candidate panel。这不改变 Rust engine、ranker 或跨平台边界。
- 输入菜单的 `menu` 只承载 input-method-specific commands，不是自动 parent/source 身份区域。M1 没有真实命令，正式实现保持 `nil`；空白 command 行记录为 macOS 26 呈现限制，不再加入空菜单、重复标题或 placeholder。

### 光标锚点根因与 build 31

- 当前 macOS 26.5 SDK `IMKInputSession.h` 规定 `attributesForCharacterIndex:lineHeightRectangle:` 的 index 相对 inline session；有 inline session 时必须是现存字符索引，无 inline session 时使用 `0`。snapshot cursor 是允许等于 composition length 的插入位置，原实现将它直接传入，末尾位置因此越界；client 可能返回有限高度但原点为 `(0,0)` 的矩形，旧可用性判断会接受该合法形状。
- 正式 panel 现先读取 marked range：非空时把 cursor 限制到 `length - 1`，无 inline session 时传 `0`。`firstRectForCharacterRange:actualRange:` 继续使用文档绝对插入位置并允许落在 marked text 末尾；没有增加拒绝 `(0,0)` 坐标的启发式规则。
- `candidate_panel_contract` fake client 记录 character index，并在越界时返回 `{{0,0},{2,22}}`；动态覆盖 `cursor == marked length`、普通中间位置、无 marked session、绝对末尾 fallback range 和 panel 最终跟随有效行矩形。旧直接传 cursor 的实现会落入原点矩形并使 contract 失败。
- 生产行为改变后 `CFBundleVersion` 升至 `31`，contract/native build assertion 与 character-index 静态门禁同步更新。仓库修复提交时只形成代码与不安装证据，尚未使用 Apple Development identity、安装、启用或要求注销；后续实机动作另记如下。
