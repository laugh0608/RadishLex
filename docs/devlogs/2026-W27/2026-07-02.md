- 已在 `ime-crypto` 的 `android-keystore` feature 下新增 Rust raw JNI glue，Android target 默认 bridge 可通过 `JNI_OnLoad` 保存的 `JavaVM` 调用 `RadishLexAndroidKeystoreJniBridge` 的 `@JvmStatic` facade。
- Raw JNI glue 固定 Kotlin class、method name 和 descriptor：`createSigningKey`、`loadPublicKey`、`sign`、`deleteSigningKey`，并读取 `RadishLexAndroidKeystoreBridgeResult.getPublicKey()`、`getSignature()` 和 `getErrorCode()`。

- 非 Android host 默认仍使用 unavailable bridge，不访问 Android Keystore；`backend_status()` 在真实 Android target build、Gradle build 和设备 smoke 通过前继续返回不可生产签名状态。
- 已将 Rust ignored `android_keystore_smoke` 推进为 Android target 上的 create / load / sign / verify / delete 流程；在非 Android host 上仍只验证 production status 阻断，不触碰 Android Keystore。
