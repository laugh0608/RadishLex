## 本周目标

- 完成 Manager 通过真实 Rust bridge 执行的本地 HTTPS 合成同步资格链。

- 复用既有 sync/crypto/userdb orchestration，经真实 Caddy HTTPS 证明双客户端同步、冲突恢复、第二轮收敛与资源清理。
