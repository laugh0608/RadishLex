## 2026-08-10：revision profile 修复与 pair 双侧门禁

- Rust manifest 校验改为先验证 canonical positive Debian revision，再精确绑定 package version 中的 product version/build number 与 manifest 字段；不把 revision 限死为 1，也不放宽 product/build/data contract。
- 合成 actual relationship fixture 新增 revision 1→2 upgrade 正向路径，并继续拒绝 manifest product version/build 漂移。Linux product 113 项测试全部通过。
