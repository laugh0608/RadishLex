- 工作从干净且与 `origin/dev` 对齐的 `c6d7b00` 开始；M5-P03 已完成，当前主批次为 M5-P04 Linux Manager、同库个人化与本地管理验收。
- 新增 `docs/linux-manager-local-acceptance.md`，固定 Linux Flutter host、staged bundle `.so`、共享 XDG resolver、product/demo 隔离、WAL/busy/migration、同库双端证据和桌面验收矩阵。现有 Flutter UI、ManagerBridge、ABI v9 与 Rust userdb/ranker 直接复用，不重写业务真相源。
- Linux privacy 真相源固定为独立 `${XDG_CONFIG_HOME}/radishlex/privacy-mode.json`，避免 Fcitx 输入热路径解析持续演进的 Manager settings。文件使用严格 format v1、私有权限、原子替换和读回；非法状态在 Manager 失败关闭，在 addon 投影为 privacy enabled。
- 普通应用学习不能从当前 `context_known=0` 直接放开。后续只使用 Fcitx 公开 program identity 做平台内固定粗分类，原始值不跨 FFI、不持久化、不记录；程序 identity 与 sensitive 传播须经 Wayland/X11 实机评审后才能进入 allowlist。unknown 和当前 GTK4 `PRIVATE` 缺口继续失败关闭。
- 首个代码批次固定为真实 Linux runner、engine 前 umask、共享 XDG、固定 bundle `.so`、平台中立 Dart bootstrap，以及 personalized runtime 写入—Manager bridge 刷新—另一 runtime 观察的产品双端自动证据；不以空 runner、fixture 或单连接 SQLite 测试作为完成。
- 生成与 Flutter 3.44.0 锁定模板一致的 Linux runner，并立即接入 `dev.radishlex.manager/runtime`：runner 在 engine 前设置 `umask(0077)`，从 executable 固定派生 `lib/libradishlex_ime_ffi.so`，直接复用共享 XDG resolver；Dart 路径模型只接受固定 `.dylib`/`.so` basename，错误语义改为平台中立并保留 macOS 回归。
- 新增严格 `privacy-mode.json` platform contract：缺省、true/false、非法格式/版本/类型/大小、宽权限、symlink/hardlink、原子临时文件、文件/目录 fsync、read-back 与 absent rollback 均由共享 C++ 实现。异常路径采用单次 descriptor 所有权关闭，避免解析或 rename 失败后重复关闭；Manager host 已接 read/write/restore/secure method channel，addon watcher 尚未进入本子批。
- 新增 `build-manager-linux-product.sh` 与 `check-manager-linux-product.sh`，固定 workspace native-rime 构建、Flutter staged bundle `.so` 装配、ELF dependency/RPATH/symbol 和无 GUI FFI smoke。当前 macOS 没有 Linux GTK/Flutter 编译环境，真实 bundle 命令尚未执行，不把源码或 Apple clang contract 写成 Linux 产品通过。
